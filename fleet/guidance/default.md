# Default task guidance

- Read Goal, Scope and Verify before the first edit. Edit only files under Scope.
- Work the Todo list in order. Re-read the task note before each item, since the user may have edited it.
- Check off an item in the note as soon as it is done. Add newly found work as new unchecked items.
- Commit after each completed item with a message that starts with the task id.
- Run the Verify steps before writing Handoff. Record the commands and their results there.
